# 智慧医疗在线问诊处方系统 - 需求说明

## 项目背景
本系统为本院药房及临床科室医生设计，支持线上图文问诊，为行动不便、路途较远或慢性病需要定期复诊的患者提供送药上门服务，节约患者就医时间与医疗资源。

---

## 1. 业务目标

### 1.1 系统用户
- **患者**：发起问诊、查看处方、在线支付、接收配送
- **医生**：线上接诊、回复病情、开具处方
- **药师**：审核处方、配药发药
- **管理员**：维护账号与药品目录、操作日志审计

### 1.2 解决问题
- 患者不用跑医院就能完成问诊、开方、缴费、取药全流程
- 医生线上接诊，提高接诊效率
- 药师线上审方配药，缩短取药等待时间

### 1.3 核心价值
- 缩短就医取药流程，减少患者往返医院次数
- 方便慢性病复诊、时间不充裕、行动不便的患者
- 节约医疗资源，提升药房与科室运转效率

---

## 2. 非功能需求

| 属性 | 要求 |
|---|---|
| 并发性能 | 支持 100 用户同时在线，问诊消息响应时间 < 2 秒 |
| 可用性 | 工作日 8:00-22:00 系统可用，故障恢复时间 < 30 分钟 |
| 安全性 | 患者病历信息加密存储，所有操作留日志，按日志号可回溯 |
| 数据一致性 | 处方状态流转全程可控，支付成功后状态必变为待配药，不丢单 |
| 易用性 | 患者端操作步骤 ≤ 3 步完成问诊发起，无需培训即可使用 |
| 兼容性 | 支持 PC 浏览器访问，界面适配主流分辨率 |

---

## 3. 核心概念

### 3.1 处方
处方不是普通药单，必须经过完整流程：医生开具 → 药师审核 → 患者缴费 → 药房配药 → 派送完成，全程状态可控。

### 3.2 问诊
问诊是医患图文会话，不是即时聊天，有明确的开始和结束状态，会话记录可回看。

### 3.3 审方
药师审查处方用药合理性，包括配伍禁忌、用法用量、适应症与诊断匹配度，审方不通过则退回医生修改。

---

## 4. 功能范围

| 模块 | 功能 |
|---|---|
| 用户注册登录 | 患者扫码注册、统一登录、按角色路由工作台 |
| 线上问诊 | 患者选医生、图文收发消息、会话记录保存 |
| 处方开具 | 医生检索药品、添加用法用量、提交处方 |
| 处方审核 | 药师审核通过/驳回、填写理由、通知医生 |
| 确认支付 | 患者填抓药信息、自动算费、模拟在线支付 |
| 配药派送 | 药师接单抓药、代煎登记、外卖配送、验证码收货 |
| 后台管理 | 管理员维护账号、药品目录、查询操作日志 |
