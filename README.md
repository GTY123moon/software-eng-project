# 软件工程实验项目
# 智慧医疗在线问诊处方系统 - 需求说明

## 项目背景
本系统为本院药房及临床科室医生设计，支持线上图文加视频问诊，为行动不便、路途较远或慢性病需要定期复诊的患者提供电子处方流转服务，患者凭电子处方到院药房取药或社会药店购药，节约患者就医时间与医疗资源。

---

## 1. 业务目标

### 1.1 系统用户
- **患者**：发起问诊、查看处方、凭处方取药或购药
- **医生**：线上接诊、回复病情、开具处方、按排班承担白天坐诊与夜间值班任务
- **药师**：审核处方、配药发药
- **管理员**：维护账号与药品目录、配置医生值班排班、操作日志审计

### 1.2 解决问题
- 患者不用跑医院就能完成问诊、开方、缴费、取药全流程
- 医生线上接诊，AI 自动整理病历减少重复问诊工作量，提高接诊效率
- 药师线上审方配药，AI 自动校验药物风险，缩短取药等待时间
- 覆盖全时段轻症咨询需求，急症自动引导线下就医，避免非工作时间无人响应
### 1.3 核心价值
- 缩短就医取药流程，减少患者往返医院次数
- 方便慢性病复诊、时间不充裕、行动不便的患者
- 节约医疗资源，提升药房与科室运转效率
- 通过 AI 前置辅助实现智慧诊疗，从人工流程升级为 AI 辅助的闭环服务

## 2. 非功能需求

| 属性 | 要求 |
|---|---|
| 并发性能 | 支持 1000+ 用户同时在线，问诊消息响应时间 < 2 秒，AI 预问诊接口响应 < 1 秒 |
| 可用性 | AI 智能引擎 7×24 小时全时段值守；常规坐诊医生 8:00-22:00 在线接诊，夜间 22:00 - 次日 8:00 安排值班医生轮值，普通咨询响应≤30 分钟，识别到急症自动引导患者线下就医；系统故障恢复时间 < 30 分钟 |
| 安全性 | 患者病历信息加密存储，所有操作留日志，AI 转诊、风险事件单独标记，按日志号可回溯 |
| 数据一致性 | 处方状态流转全程可控，支付成功后状态必变为待配药，不丢单 |
| 易用性 | AI 引导患者结构化描述病情，患者端操作步骤 ≤ 3 步完成问诊发起，无需培训即可使用 |
| 兼容性 | 支持 PC 浏览器访问，界面适配主流分辨率 |

## 3. 核心概念

### 3.1 处方
处方不是普通药单，必须经过完整流程：医生开具 → AI 校验 → 药师审核 → 患者凭电子处方取药或外购，全程状态可控。

### 3.2 问诊
问诊是医患图文加视频会话，不是即时聊天，有明确的开始和结束状态，会话记录可回看；问诊全程由 AI 自动整理要点，区分白天坐诊与夜间值班接诊场景。

### 3.3 审方
药师审查处方用药合理性，包括配伍禁忌、用法用量、适应症与诊断匹配度，AI 先完成初筛标记风险，药师做最终人工判断；审方不通过则退回医生修改。

### 3.4 AI 智能辅助
AI 是系统的智慧核心，不替代医生做最终诊疗判断，而是在流程节点上做辅助：预问诊阶段引导患者结构化描述病情、自动识别急症风险、生成病情摘要供医生参考；开方 / 审方阶段自动校验药物配伍禁忌与剂量异常，减少人工重复劳动

## 4. 功能范围

| 模块 | 功能 |
|---|---|
| 用户注册登录 | 患者扫码注册、统一登录、按角色路由工作台 |
| 线上问诊 |患者选医生、AI 引导式预问诊采集病史与症状、AI 风险分级与病情摘要生成、图文收发消息、会话记录自动整理、夜间咨询自动派单给值班医生|
| 处方开具 | 医生参考 AI 生成的病情摘要、检索药品、添加用法用量、AI 自动校验药物禁忌后提交处方 |
| 处方审核 | 药师参考 AI 初筛的处方风险提示、审核通过 / 驳回、填写理由、高风险处方触发双人审核、通知医生 |
| 确认订单 | 患者填抓药信息、自动计费、在线支付 |
| 药品派送 | 药师配药扣减库存、发药确认、患者凭电子处方到院取药或社会药店外购 |
| 后台管理 | 管理员维护账号、药品目录、配置医生夜间值班排班、查询操作日志与 AI 转诊风险记录 |
