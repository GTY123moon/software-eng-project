# 前端页面修改指南（患者端）

> 面向：只想把界面改好看、不碰后端逻辑的同学。照着本指南定位文件、改样式即可，不需要写 Python。

## 一、先搞清楚：这套系统前后端各在哪

- **后端（Python / Django）**：`accounts/views.py` 负责取数据库数据、校验、跳转；`accounts/urls.py` 负责网址和页面的对应。**改界面一般不用动这两个文件。**
- **前端（你要改的部分）**：
  - 页面骨架（标题、按钮、表格、文案摆在哪）→ `templates/accounts/*.html`
  - 颜色、大小、圆角、间距、排版 → `static/css/accounts.css`（患者端）、`static/css/base.css`（全站公共导航/背景/字体）
  - 通话弹窗脚本 → `static/js/video_call.js`（样式问题不用动它）

一句话：**页面上显示什么文字、放哪些控件，在 HTML 模板；长什么样（颜色/圆角/间距/字号），在 CSS。**

## 四、模板里哪些能改、哪些别动

HTML 模板里除了普通标签，还夹着 Django 模板语法：

### 可以随便改
- 普通文字、标题、按钮文案、提示语
- 控件的排列顺序、增删一个纯展示用的 `<div>` / `<span>`
- 给元素加 `class="xxx"`，再去 CSS 里写对应样式

### 不能删、不能改名（会导致页面报错）
- `{% url 'accounts:xxx' %}`：网址生成器，链接地址由它生成，不要手写死路径，也不要改引号里的名字。
- `{{ 变量 }}`：后端传来的数据（如 `{{ patient.name }}`、`{{ c.doctor }}`），保留原样显示；不要删掉花括号。
- `{% for c in history %} ... {% endfor %}`：循环列表，开头 `for` 和结尾 `endfor` 必须成对。
- `{% if active.assessed %} ... {% else %} ... {% endif %}`：条件判断，`if` 和 `endif` 必须成对。
- `{% load static %}` 与 `{% static 'css/...' %}`：静态资源引用，保留。

> 拿不准时：只在标签内部改 `class`、文字和样式，不动花括号与 `{% %}`，基本不会出错。

## 五、全局视觉统一改（颜色 / 字体 / 圆角 / 阴影）

### 1. 主色调
全站蓝色集中在两处：
- `static/css/base.css`：顶部导航背景 `#1f6fb2`。
- `static/css/accounts.css`：按钮、链接、标题蓝 `#1976d2`、`#0d47a1`。

想整体换配色，把这几个蓝值统一替换即可。医疗类常用配色参考：

| 用途 | 现状 | 可替换为 |
| --- | --- | --- |
| 主按钮 / 链接 | `#1976d2` | `#0e7c7b`（青绿）、`#2563eb`（沉稳蓝） |
| 深色标题 / 顶栏 | `#0d47a1` / `#1f6fb2` | `#0f5f5c` / `#1e3a8a` |
| 页面背景 | `#f5f7fa` | `#f3f6f8` |
| 成功/进行中绿 | `badge-green` | `#2e7d32` |
| 警示/高危红 | `badge-red` | `#c62828` |

### 2. 圆角与卡片阴影
- 卡片圆角：`.card`、`.doctor-card`、`.login-card` 里的 `border-radius`，改大更柔和（如 `16px`），改小更硬朗。
- 卡片阴影：`box-shadow`，调透明度或模糊范围（如 `0 4px 16px rgba(0,0,0,.08)`）。

### 3. 字体与字号
- 全局字体在 `base.css` 的 `body`：`font-family: "Microsoft YaHei", Arial, sans-serif;`
- 标题字号找对应类里的 `font-size`；正文一般 14px，卡片标题 16–18px。

### 4. 间距
- 卡片内边距 `padding`、卡片之间的间距 `gap` / `margin`；横向排列用 Flex（`display: flex; gap: 14px;`）。

## 六、逐页面美化建议

### 工作台 `dashboard.html`
- 顶部三张 `.stat-card`：调大数字 `.stat-num` 字号、给不同卡片配浅色底纹（蓝/绿/橙）。
- 左侧 `.side` 菜单：当前选中项 `.side-item.active` 的背景与加粗。
- `.entry-card` 快捷入口：加图标底色、hover 上浮效果（参考现有 `.entry-card:hover`）。

### 选医生 `consult_create.html`
- `.doctor-card`：医生头像位可放圆形占位 `div`；忙碌/离线卡片的灰化态已由 `.doctor-card.disabled` 处理，不要覆盖。
- 状态徽章 `.badge`：进行中蓝、已结束灰、高危红。

### AI 评估页 `consult_assess.html`
- `.ai-card`：放 AI 头像/图标；风险等级用 `.badge-red`（高危）/`.badge-green`（中低危）突出。
- 表单 `.form-textarea`：加大输入框高度、聚焦时边框变色。

### 对话页 `consult_chat.html`
- 气泡：患者靠右 `.msg-row.mine .msg-bubble`，医生靠左；调气泡圆角、最大宽度、内边距。
- 输入区 `.chat-input`：贴底固定、textarea 自适应；视频弹窗结构在模板底部，样式参照 `.msg-*`。

### 消息列表 / 处方
- 列表条目 `.list-item`：左右对齐、时间灰色弱化；处方表格 `.presc-table` 斑马纹与表头底色。

## 七、用浏览器 F12 定位元素（最常用的改样式方法）

1. 页面上按 `F12` 打开开发者工具，点左上角「箭头」图标（或 `Ctrl+Shift+C`）。
2. 点中页面上你想改的元素，右侧会显示它的 `class` 和生效的 CSS 规则。
3. 在右侧样式面板里直接改颜色、尺寸，能实时预览；满意后把对应规则抄回 `accounts.css` 保存。
4. 找不到对应类时，先在 `accounts.css` 顶部搜类名（如 `chat-input`），定位到行号再改。

## 八、建议自学顺序（课设范围内够用即可）

1. **HTML 标签**：`div / span / h1-h3 / p / a / button / input / textarea / table` 各自作用。
2. **CSS 基础**：颜色 `color/background`、盒模型 `padding/margin/border`、`border-radius`、`box-shadow`、`font-size`。
3. **布局**：`display: flex` 一行内排列 + `gap` 间距；`display: grid` 卡片网格；`align-items / justify-content` 对齐。
4. **状态伪类**：`:hover` 鼠标悬停、`:focus` 输入聚焦。
5. **Django 模板**：只需要会读 `{{ 变量 }}`、`{% for %}`、`{% if %}`、`{% url %}` 这几种，不用学后端语法。

推荐查资料：MDN Web Docs（`developer.mozilla.org/zh-CN`）搜任意 HTML/CSS 属性，例子可直接抄。

## 九、常见问题

- **改了 CSS 页面没变化**：`Ctrl + F5` 强制刷新；确认改的是 `static/css/accounts.css`，且模板里引用路径没动。
- **改 HTML 后报错 `TemplateSyntaxError`**：多半是删了 `{% %}` 或 `{{ }}` 里的内容，或 `for/if` 没有对应结尾标签，对照第四节补回。
- **想加一个全新页面**：先在 `urls.py` 加路由、`views.py` 加视图（这两步找后端同学），页面模板和样式按本指南做。
- **三端（医生/药师/管理员）页面目前还是占位骨架**：后续补页面时，可直接复用患者端这套 CSS 类，保持风格统一。
